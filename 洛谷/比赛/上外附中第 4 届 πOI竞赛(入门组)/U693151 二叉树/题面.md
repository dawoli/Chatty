# U693151 二叉树



## 题目描述



## 题目描述

给定一棵**按层序编号的完全二叉树**，每个节点初始有一个小写字母。

接下来有 $q$ 次修改操作：每次修改一个节点的字符。



每次修改完成后，统计树上满足条件的节点数量：该节点的**整棵子树**内的所有字符，重新排列后可以构成回文串。



初始状态也需要先输出一次答案。



## 输入格式



第一行两个正整数 $n,q$，分别表示节点数量、操作次数。

第二行一个长度为 $n$ 的字符串，第 $i$ 个字符表示编号为 $i$ 的节点的初始字符。

接下来 $q$ 行，每行一个整数 $x$ 和一个字符 $ch$，表示将节点 $x$ 的字符修改为 $ch$。



## 输出格式



第一行输出初始状态的答案。

接下来每行依次输出每次修改后的答案。



## 输入输出样例 #1



### 输入 #1



```
4 2
aabc
1 b
2 c

```



### 输出 #1
```
2
2
4
```



## 说明/提示



### 数据范围

所有字符均为小写英文字母。

- 测试点 1~3：$1 \le n,q \le 20$

- 测试点 4~7：$1 \le n,q \le 10^3$

- 测试点 8~10：$1 \le n,q \le 10^5$
