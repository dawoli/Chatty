\# U693150 string swap



\## 题目描述



\## 题目描述

给定长度为 $n$ 的数字序列 $a\_1,a\_2,\\dots,a\_n$。

你可以进行任意多次操作：每次选择两个下标 $i,j$，满足 $l \\le |i-j| \\le r$，交换 $a\_i$ 与 $a\_j$。



请通过若干次交换，使得序列的\*\*字典序最小\*\*，输出最终序列。



\### 字典序定义

对于两个等长序列 $A,B$，找到第一个不同的位置 $k$：

\- 若 $a\_k < b\_k$，则 $A$ 字典序更小；

\- 若 $a\_k > b\_k$，则 $B$ 字典序更小。



\## 输入格式



第一行三个正整数 $n,l,r$。

第二行一个长度为 $n$ 的字符串，表示初始序列。



\## 输出格式



输出一个字符串，表示字典序最小的序列。



\## 输入输出样例 #1



\### 输入 #1



```

5 1 1

54321

```



\### 输出 #1



```

12345

```



\## 输入输出样例 #2



\### 输入 #2



```

5 4 4

54321

```



\### 输出 #2



```

14325

```



\## 输入输出样例 #3



\### 输入 #3



```

5 3 4

54321

```



\### 输出 #3



```

12345

```



\## 说明/提示



\### 样例说明

样例1：$l=r=1$，相当于只能交换相邻元素，交换相邻元素可以将整个序列变成从小到大的(冒泡排序思想)。

样例2：仅可交换下标距离等于 4 的数字，即位置 1 和位置 5，所以交换这两个位置的数字，得到字典序最小的序列。

样例3：可以交换下标距离为 3 或 4 的数字，经过若干次交换后可得到升序序列，交换方法不唯一，仅需输出最终序列即可。



\### 数据范围

$1 \\le n \\le 10^5,\\ 1 \\le l \\le r < n$

\- 测试点 1\~3：$l=r$

\- 测试点 4\~7：$l \\times 2 < n$

\- 测试点 8\~10：无特殊限制
