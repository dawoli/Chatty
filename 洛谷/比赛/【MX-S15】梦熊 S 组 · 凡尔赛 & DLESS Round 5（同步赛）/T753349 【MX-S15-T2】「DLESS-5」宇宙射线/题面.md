# T753349 【MX-S15-T2】「DLESS-5」宇宙射线

## 题目描述

给定一个 $1\sim n$ 的排列 $a$，下标从 $1$ 开始，现在有如下一段对 $a$ 进行标准的冒泡排序伪代码：
$$
\begin{aligned}
&\text{01: } \textbf{Algorithm } \text{BubbleSort}(a, n) \\
&\text{02: } \quad \textbf{for } i \leftarrow 1 \textbf{ to } n \textbf{ do} \\
&\text{03: } \quad\quad \textbf{for } j \leftarrow 1 \textbf{ to } n-i \textbf{ do} \\
&\text{04: } \quad\quad\quad \textbf{if } a[j] > a[j+1] \textbf{ then} \\
&\text{05: } \quad\quad\quad\quad \text{Swap}(a[j], a[j+1]) \\
&\text{06: } \quad\quad\quad \textbf{end if} \\
&\text{07: } \quad\quad \textbf{end for} \\
&\text{08: } \quad \textbf{end for} \\
&\text{09: } \textbf{end Algorithm}
\end{aligned}
$$

由于宇宙射线的影响，导致第 4 行的 `if` 语句在执行时，**恰好有一次**其的执行结果相反（即执行相反的分支）。

现在给出 $n,a$，求出在宇宙射线影响下，运行 `BubbleSort(a,n)` 后，本质不同的 $a$ 的个数（称两个排列 $p,q$ 本质不同，当且仅当 $\exist i\in [1,n],p_i\neq q_i$）。

## 输入格式

第一行，一个正整数 $n$。

第二行，$n$ 个用空格隔开的正整数，表示排列 $a$。

## 输出格式

一行，一个正整数，表示答案。

## 输入输出样例 #1

### 输入 #1

```
3
2 3 1
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
5
1 4 2 3 5
```

### 输出 #2

```
5
```

## 说明/提示

### 样例 1 解释

可能的 $a$ 有：

- $[1,3,2]$。
- $[2,3,1]$。
- $[2,1,3]$。

对于所有数据，保证：
- $2\leq n\leq 2\times10^6$；
- 输入的 $a$ 是一个排列。
