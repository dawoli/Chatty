## 题意

给定序列 $a_1,a_2,\ldots a_n$。对于序列 $b_1,b_2,\ldots ,b_m$，定义能量：

$$E(b)=\sum_{i=1}^{m}(-1)^{i+1}b_i$$

需要删除一个非空连续区间 $[l,r]$，剩余元素按原相对顺序拼接。求有多少个区间使得删除后能量等于 $k$。

## 转化

定义**带符号前缀和**：

$$P_i=\sum_{t=1}^{i}(-1)^{t+1}a_t,P_0=0$$

考虑删除 $[l,r]$，令 $i=l-1,j=r$

若 $j-i$ 为**偶数**，后半段符号**不变**，删除后能量为：

$$P_i+P_n-P_j$$

若 $j-i$ 为**奇数**，后半段符号**翻转**，删除后能量为：

$$P_i+P_j-P_n$$

因此只需要统计满足条件的二元组 $(i,j)$，其中 $0\le i<j \leq n$。

## 计数

设删除后能量等于 $k$。

若 $j-i$ 为**偶数**，则 $i,j$ **同奇偶**，需要：

$$P_j-P_i=P_n-k$$

若 $j-i$ 为**奇数**，则 $i,j$ **异奇偶**，需要：

$$P_i+P_j=P_n+k$$

从左到右枚举 $j$，用两个**哈希表**（`unodered_map`）分别维护此前**偶数下标**和**奇数下标**的 $P_i$ 出现次数。

对于当前 $j$，查询**同奇偶**中的 $P_i=P_j-(P_n-k)$，以及**异奇偶**中的 $P_i=P_n+k-P_j$，累加答案后再加入 $P_j$。

时间复杂度为 $O(n)$ 或 $O(n \log n)$，空间复杂度为 $O(n)$。

## Code

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve()
{
	int n;
	ll k;
	cin >> n >> k;
	vector<ll> a(n + 1);
	for(int i = 1; i <= n; ++i)
	{
		cin >> a[i];
	}

	vector<ll> p(n + 1, 0);
	for(int i = 1; i <= n; ++i)
	{
		if(i % 2 == 1)
		{
			p[i] = p[i - 1] + a[i];
		} else
		{
			p[i] = p[i - 1] - a[i];
		}
	}

	ll t1 = p[n] - k;
	ll t2 = p[n] + k;
	unordered_map<ll, int> odd, even;
	even[0] = 1;
	ll ans = 0;
	for(int j = 1; j <= n; ++j)
	{
		if(j % 2 == 0)
		{
			auto it = even.find(p[j] - t1);
			if(it != even.end())
				ans += it->second;
			it = odd.find(t2 - p[j]);
			if(it != odd.end())
				ans += it->second;
			even[p[j]]++;
		} 
		else
		{
			auto it = odd.find(p[j] - t1);
			if(it != odd.end())
				ans += it->second;
			it = even.find(t2 - p[j]);
			if(it != even.end())
				ans += it->second;
			odd[p[j]]++;
		}
	}
	cout << ans << endl;
}

int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int t;
	cin >> t;
	while(t--)
	{
		solve();
	}
	return 0;
}
```
