环形DP / 断环分类讨论

**思路**：
- 环上"任意选 B 小时小睡、可多段、每段第一小时收益为 0"的 DP。
- **不要用倍长数组**（同一小时会出现两份，可被重复选中 → 答案偏大）。
- 在 1 号小时处断环，分两类跑两遍线性 DP：
  1. 1 号不睡：环退化为线性，直接线性 DP。
  2. 1 号睡：把它当某段的入睡起点（收益 0）；最后若 N 号也睡，说明该段跨越 N→1 边界，
     补 +u[1]（题面：睡 N 和 1 得 U₁）。
- 取两遍最大值。

**错点**：
- 倍长数组：位置 i 与 i+N 是同一小时，DP 可同时选中两份 → 把最优小睡段复制一份白拿收益，
  答案偏大（P6064_7 多算 3,337,926）。回溯确认选中了 [5,6,7,13,14,15] = 小时 5,6,7 各两份。
- 防重复 ⟺ 限制选中跨度 ≤ N−1（鸽笼原理），但强制跨度需枚举窗口起点，O(N²B) 不可行；
  断环分类是 O(N·B) 的标准做法。

**关键结论**：
- 倍长数组只在"解天然落在长度 ≤ N 的连续窗口内"的问题中安全（环形最大子段和、
  环上固定长度窗口最值）；"任意选点 + 可多段"的环 DP 不能用倍长。
- 区分标准：最优解是否天然落在某个长度 ≤ N 的连续窗口里。
