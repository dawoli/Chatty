# 离散化 B3694 【模板】数列离散化

- **题目链接**：https://www.luogu.com.cn/problem/B3694
- **算法标签**：离散化、排序

## 算法思路

将原数组拷贝到辅助数组 `b` 中，对 `b` 排序后去重，然后对每个 `a[i]` 在 `b` 中二分查找其排名（下标 +1）。

## 踩坑点

- `lower_bound` **必须**在 **有序**区间上使用
- 原数组 `a` 是原始输入顺序，不能直接在 `a` 上做二分查找
- 去重后 `len = unique(b + 1, b + n + 1) - (b + 1)` 得到有效元素个数

## 关键结论

离散化三步走模板：

1. 拷贝：`b[i] = a[i]`
2. 排序去重：`sort(b+1, b+n+1); len = unique(b+1, b+n+1) - (b+1)`
3. 查排名：`lower_bound(b+1, b+len+1, a[i]) - b`
