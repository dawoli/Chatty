# 字典序BFS 图论 P15261 [USACO26JAN2] Lexicographically Smallest Path G

- 题目链接：https://www.luogu.com.cn/problem/P15261
- 算法：按字典序逐层 BFS + 同层环判无穷
- 复杂度：$O(N+M)$
- 状态：WA 8pts（只做了"全是 a"的特殊性质）

## 题意

无向连通图，$N$ 个点，$M$ 条边，每条边带一个小写字母，可能有重边和自环。路径可以重复经过边。$f(1,i)$ 为从 1 到 $i$ 的所有路径中，边字符依次连接所得字符串的字典序最小者。对每个 $i$ 求 $f(1,i)$ 的长度；若不存在最小串（可以无限延长而字典序不变）输出 $-1$。

## 我的做法（8 分）

只处理了"所有边字符都是 a"的性质（测试点 3-4）：此时任何路径的串都是 `aaa...`，字典序最小等价于路径最短，直接 BFS 求最短边数。

```cpp
if (al_a) all_a();
for (int i = 1; i <= n; i++) cout << dis[i] << " ";
```

问题：

- 非全 `a` 时根本没有执行 BFS，`dis` 保留上一组的残留值（多组数据只在 `all_a()` 里 `fill`），等于输出垃圾；
- 一般情况完全没有思路。

## 正确方向

字典序最短路不能套普通最短路（边权不是数值）。标准做法是按"当前最优前缀"逐层扩展：

1. 第 0 层：`{1}`，长度 0。
2. 已知第 $d$ 层节点集合 $S_d$（这些点的最优串长度都是 $d$，且前缀相同），考察所有从 $S_d$ 出发的边，取**最小字符** $c$。
3. 只沿字符 $c$ 的边扩展，得到 $S_{d+1}$，这些点的答案长度为 $d+1$。
4. 若沿字符 $c$ 的边能回到 $S_d$ 内部（或回到已经以同一前缀出现过的层），说明可以在这条最优前缀上无限重复字符 $c$，串长无界而字典序不变 $\Rightarrow$ 这些点答案 $-1$。

实现要点：

- 每层只保留"当前前缀最小的那些点"，其余点这一轮不扩展；
- 判定环时看目标点是否已经在同层 / 更早的合法层；
- 重边保留字符最小的那条（我的 `add_edge` 这部分是对的）。

## 易错点

- 多组数据必须清空 `dis` 和邻接表；只在某个分支里清空会导致其他分支输出残留值。
- 字典序比较不是"边权相加"，不能直接 Dijkstra / SPFA。
- `-1` 的判定是"最优前缀上存在同字符环"，不是"图里有环"。
- 自环：字符为 `a` 的自环直接使该点 $-1$（样例 1 的第二个测试点）。

## 关键结论

字典序最短路径 = 按字符逐层 BFS，每层只沿最小字符扩展；无穷解来自"最优前缀上的可重复同字符环"。
