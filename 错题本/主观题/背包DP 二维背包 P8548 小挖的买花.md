题目链接：https://www.luogu.com.cn/problem/P8548
标签：背包DP / 二维背包（0/1 背包 + "≥"下限约束维）

**思路**：
- 状态：`dp[j][fr]` = 总价 ≤ j、新鲜度总和 ≥ fr 时美丽度最大值。
- 价格维：至多（≤）容量维，标准 0/1 背包逆序滚动即可。
- 新鲜度维：至少（≥）下限维，取第 i 株花从 `dp[j-c][max(0, fr - fr_i)]` 继承；
  `fr - fr_i ≤ 0` 说明单株花新鲜度已够，回退到空集 base `dp[*][0]`。
- 初始化：`dp[i][0] = 0`（空集满足"≥0"），`dp[i][j≥1] = -INF`。
- 查询 O(1)：直接 `dp[c][f]`（状态本就是"≥ f"），不可达（-INF）输出 0。

**错点**：
- base 初始化不精确：漏置/误置导致非法转移"从 0 拔地而起"（如"0 钱却有正新鲜度"被视为可达）。
- ≥ 维转移不 clamp：`fr < fr_i` 时越界 / 漏掉"单株已够"的转移 → 答案偏小。
- 查询向后搜新鲜度：误把状态当"恰好 fr"，对 `fr' ≥ f` 取 max；状态已是 ≥，直接 `dp[c][f]`。

**关键结论**：
- "≥ 约束"维度通用做法：转移 clamp 到 0 + base 状态 `dp[*][0] = 0`。
- 判断维度性质：读题关键词——"至多/不超过"→ ≤ 容量维；"大于等于/至少"→ ≥ 下限维。
- 复杂度 O(n·C·F)，C=F=500 时 ≈ 1.25e8（O2 可过 1s）；q ≤ 1e6 必须查询 O(1)。
