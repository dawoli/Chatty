# 贪心 + 优先队列 P15848 [NOISG 2026 Finals] 饿猫 Famished Cats

- 题目链接：https://www.luogu.com.cn/problem/P15848
- 算法：对称位贪心 + 前缀和 + 大根堆
- 复杂度：时间 $O(n\log n)$，空间 $O(n)$

## 题意

$n$（偶数）间房排成一条线。第 1 间到起点距离 $d_1$，第 $i$ 间到第 $i-1$ 间距离 $d_i$。卡车初始油量 $x$，进入第 $i$ 间先消耗 $d_i$，再收集 $f_i$ 单位燃料。可以做任意次操作：交换第 $i$ 间与第 $n-i+1$ 间的燃料（两侧燃料都没被用过才能换）。

求能到达的最远房号 $D$，以及到达 $D$ 所需的最少交换次数 $S$。

## 思路

**第一步：求 $D$。** 每一对 $(i,\,n-i+1)$ 只能内部互换。把每对里较大的燃料放到靠近起点的一侧（用副本 `tf`），顺序模拟，得到 $D$。

这是上界，也是可达的：一对里的两笔燃料总量不变，把大的提前只会让油更早到位；第 $i$ 间一定在第 $n-i+1$ 间之前经过。

**第二步：求最小 $S$。** 只需模拟前 $n/2$ 间。用大根堆存每一对"交换收益"

$$
g_i = f_{n-i+1} - f_i \quad (g_i > 0\ \text{才入堆})
$$

- **(A) 当前油量不足**：取堆顶收益补油，计数 $+1$，`pop` 掉。
- **(B) 远端可达性检查**：主循环只走到 $n/2$，看不到后半程。用前缀和建模：

$$
b_j = x_0 + \sum_{k<j} f_k - \sum_{k \le j} d_k
$$

即"一次交换都不做时，进入第 $j$ 间的余油"。交换第 $p$ 对等价于给

$$
b_{p+1},\ b_{p+2},\ \dots,\ b_{n-p+1}
$$

整体加 $g_p$。所以第 $ii=n-i+1$ 间可达的充要条件是

$$
b_{ii} + \sum_{p \le i} g_p \ge 0
$$

代码里写成 `qz[ii-1] + x0 + exs < qzd[ii]` 时继续取堆顶。$ii>D$ 不用查。

## 易错点（两次 WA 的真实原因）

第一次 WA（10/21）：只按前半程余油判断，且 (A) 段取堆顶后**没有 `pop`**，失败时还回滚了已做的交换。

- 不 `pop` 会让同一对反复 `swap`：换两次等于没换，`exs` 和 `s` 双双虚增。
- 回滚把本来必要的交换撤销，导致后面 (B) 的累计收益少算。

第二次 WA 7pts（10/22）：补上了 (B)，但 (A) 段仍然漏 `q.pop()`，且保留了 `if (x < 0) { s -= add; break; }`。

AC（10/24）：删掉回滚，补上 `q.pop()`。

**本质**：

- `x < 0` 只表示"现在需要一次交换"，不代表"到不了"。$D$ 已由第一步保证可达，交换只是把后半程的燃料提前搬过来。
- 堆里每个候选只能用一次，取完必须 `pop`。

## 关键结论

- 只有对称对能互换、且两侧燃料总量不变 $\Rightarrow$ $D$ 可以用"大的放近端"贪心求出。
- 判断够不够油不能只看当前余油：一次交换等价于对一段区间整体加正收益，要用前缀和 + 累计收益判定远端。
- 最少交换次数 = 每次取当前收益最大的交换（堆贪心），且收益必须为正才入堆。
