题目链接：https://www.luogu.com.cn/problem/P9188
标签：字符串计数 DP / 子序列自动机 / 累加贡献

**思路**：
- 定义 `f(t)` = 字符串 `t` 中最多能组成多少个**不重叠**的 "bessie" 子序列（贪心反复匹配）；题目求所有子串 `t` 的 `f(t)` 之和。
- `pre[1..6]` 追踪 "bessie" 各前缀作为子序列的**最右匹配起点**：
  - `'b'` → `pre[1]=i`；`'e'` → `pre[2]=pre[1]`、`pre[6]=pre[5]`；
  - `'s'` → 先 `pre[4]=pre[3]`、再 `pre[3]=pre[2]`（从后往前）；`'i'` → `pre[5]=pre[4]`。
- 设 `j=pre[6]`（当前右端点 `i` 处完整 "bessie" 的最右起点）。因为 `j` 最右，左端点 `l>j` 时子串里不存在完整匹配，故：
  `f(s[l..i]) = (l <= j ? 1 + f(s[l..j-1]) : 0)`。
- 于是 `dp[i] = Σ_l f(s[l..i]) = j + Σ_{l=1}^{j-1} f(s[l..j-1]) = j + dp[j-1]`，答案 = `Σ_i dp[i]`。
- 复杂度 `O(|s|)`，空间 `O(|s|)`。

**错点**：
- `case 's'` 更新顺序：必须**先 `pre[4]=pre[3]` 再 `pre[3]=pre[2]`**（从长前缀往前更新）。若反过来，同一个 `'s'` 会同时充当第一、第二个 `'s'`，导致错配（代码曾 WA 16pts）。
- 语义易混淆：本题是"最大重复次数之和 `Σ f`"。
  - 误当"至少含 1 个 bessie 子序列的子串数"：样例1 `bessiebessie` 会得 13（错，应为 14）。
  - 误当"连续子串出现次数"：`bessiebessie` 恰为 14，但一般字符串（如 `bessise`）会得 0（错）。
- 递推别写成 `dp[i]=j`（那是"含至少 1 个子序列"的起点数），正确是 `dp[j-1]+j`。
- 数据范围：`n` 可达 `3e5`，答案量级约 `O(n^3/216)≈1e14`，必须用 `long long`，且 `dp` 下标用 `pre[6]-1`（`j=0` 时取 0）。

**关键结论**：
- "可重复匹配的固定串（子序列）"计数：用 `pre[1..len]` 逐前缀追踪最右匹配起点；遇到相同字符（如两个 `'s'`）须**从长到短逆序**更新，否则同字符复用。
- "含模式子序列"的累加计数通用套路：定右端点，取该模式**最右匹配起点** `j`，则贡献可拆为 `j`（新增的完整匹配）× 前缀数 + `dp[j-1]`（沿用之前的贡献）。
- 分清三类：恰好含 k 个 / 至少含 1 个 / 可重复计数的和——本题后者，衡量的是"能挤出多少个完整的模式"。
