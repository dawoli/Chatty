计数DP / 分组背包 / 容斥

题目链接：https://www.luogu.com.cn/problem/P7224

**思路**：
- 容斥：数"积 > m"难（积无上限），改数"积 ≤ m"：答案 = 2^n − #(积 ≤ m)。
- 值为 1 的元素不影响积，任意选，最后整体乘 2^one。
- 值 > m 的元素单个就超限，永远进不了"积 ≤ m"子集，可忽略。
- 分组背包：cnt[v] 统计值为 v 的个数；dp[j] = 用 [2,m] 元素凑出积恰为 j 的子集数。
  对每个 v（cnt[v]>0），旧积 k 从 m/v 递减到 1，选 t 个转移：
  dp[v^t·k] += C(cnt[v], t) · dp[k]。
- 复杂度为调和级数 Σ_v m/v = O(m ln m)。

**错点**：
- 数组 off-by-one 越界（访问下标 MAXA）：样例能过 ≠ 无 UB，评测机可能错/崩。
- 分组背包 k 必须从大到小，否则同一组被重复使用导致重复计数。
- 转移边界含旧积 k：v^t·k ≤ m，不是 v^t ≤ m。
- v^t 用 long long 迭代维护，勿用 pow（浮点精度 + 慢）。

**关键结论**：
- "积 > X" 计数 → 反手数"积 ≤ X"：因为 ≤ 限制了取值与个数（元素 ≥2 → 子集长度 ≤ log₂m）。
- 多重集元素按值分组 + 组合数系数 = 把 O(nm) 背包压成 O(m ln m)。
