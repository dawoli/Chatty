**题目链接**：https://www.luogu.com.cn/problem/P9750

**思路**：
- 较大根不是恒为 `(-b+sqrt(delta))/(2a)`：当 `a<0` 时，两解中较大的是
  `(-b-sqrt(delta))/(2a)`，即根号前要乘 `sgn(a)`。
- 把 `delta` 分解为 `k^2 * r`（r 不含平方因子），则较大根统一写成
  `q1 + q2*sqrt(r)`，其中 `q1 = -b/(2a)`，`q2 = k/(2|a|)`。
  **q2 恒为正**（`sgn(a)/(2a) = 1/(2|a|)`），不用再判符号。
- 按题面格式拼接：
  - `r==1`（delta 为完全平方数）→ 两根都有理，直接输出有理数；
  - `q1 != 0` 先输出 `q1+`，否则跳过；
  - `q2==1` → `sqrt(r)`；`q2` 为整数 → `q2*sqrt(r)`；
  - `q2=c/d` 且 `c==1` → `sqrt(r)/d`；否则 `c*sqrt(r)/d`。
- 有理数统一用 `to_frac`：分母化正 → 除以 gcd → 分母为 1 时只输出分子。

**错点**：
- `delta==0` 必须单独处理：直接输出 `-b/(2a)`；若走分解循环，`r` 会停在 0，
  输出 `sqrt(0)` 出错。
- `delta` 是完全平方数时（如 `1 0 -4`，delta=16）若忘了先约分合并 q1、q2，
  会输出 `2*sqrt(1)` 之类的形式；必须先用 `r==1` 分支合并成单个有理数。

**关键结论**：
- 较大根统一式：`x = -b/(2a) + k/(2|a|) * sqrt(r)`（k、r 由 delta=k²r 分解）。
- `|a|,|b|,|c| <= M <= 1000`，`delta` 不超过约 `5e6`，int 足够；分解平方因子
  循环 `d*d <= r` 到约 2236，完全跑得动。
