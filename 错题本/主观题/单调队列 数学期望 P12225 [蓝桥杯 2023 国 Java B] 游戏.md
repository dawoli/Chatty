# 单调队列与期望 P12225 [蓝桥杯 2023 国 Java B] 游戏

- 题目链接：https://www.luogu.com.cn/problem/P12225
- 算法：数学期望线性性 + 单调队列
- 复杂度：时间 O(N)，空间 O(K)

## 思路

设合法窗口数为 `M=N-K+1`。熊大、熊二分别独立且等概率地选择一个窗口，记熊大窗口的最大值为 `X`，熊二窗口的最小值为 `Y`。由期望的线性性：

`E[X-Y]=E[X]-E[Y]`

两人的窗口都在同一组 `M` 个窗口中均匀选择，因此：

`E[X-Y]=(所有窗口最大值之和-所有窗口最小值之和)/M`

不必枚举两人所选窗口的所有组合。扫描数组时，用递减单调队列维护当前窗口最大值、递增单调队列维护最小值；窗口右移时移除队首的过期下标，并从队尾删除被新元素支配的元素。每个元素在每个队列中至多入队、出队一次。

## 易错点

- 直接枚举熊大和熊二所选的窗口对，需要 `M^2` 次计算；应先用期望线性性拆开。
- 若直接对两个窗口的差求平均，分母是 `M^2`，但将最大值和最小值分别求和后，分母各为 `M`。不能把两种写法的分子、分母混在一起。
- 最大值队列应保持单调递减，最小值队列应保持单调递增；队首下标小于当前窗口左端点时才过期。

## 关键结论

独立随机变量不要求逐对枚举才能计算差的期望：`E[X-Y]=E[X]-E[Y]`。先化简期望，再用滑动窗口极值结构统计，即可将平方级枚举降为线性时间。
