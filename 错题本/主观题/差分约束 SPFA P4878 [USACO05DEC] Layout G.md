差分约束 + SPFA 判负环 + 最短路

---

**思路**：

1. 把不等式约束转化为最短路形式 `dis[v] <= dis[u] + w`，建边 `u --w--> v`
   - "最多相距 D"：`x_B - x_A <= D` → 边 `A --D--> B`
   - "至少相距 D"：`x_B - x_A >= D` → `x_A - x_B <= -D` → 边 `B --(-D)--> A`
2. 添加虚拟源点 0，连所有点（权 0），跑 SPFA 检测整个图是否有负环
3. 若无负环，从节点 1 再跑 SPFA，`dis[n]` 即为 `max(x_n - x_1)` 的答案
4. 若 `dis[n]` 仍为 INF，输出 -2（无约束限制，距离可以无穷大）

---

**错点**：

1. **MD（至少相距 D）边方向搞反**
   - 把 `A - B >= D` 当作了标准形式，直接加了 `add_edge(A, B, -D)`
   - 正确做法：先化成 `x_j - x_i <= c` 的形式再建边
   - `x_B - x_A >= D` → `x_A - x_B <= -D` → 下标小的在左边 → 边 `B --(-D)--> A`

2. **顺序约束方向搞反**
   - 题目隐含"编号从小到大从左到右排列"的要求，需添加 `pos[i] ≤ pos[i+1]`
   - 错误地加了 `add_edge(i, i+1, 0)`（即 `pos[i+1] ≤ pos[i]`，方向反了）
   - 正确应为 `add_edge(i+1, i, 0)`（即 `pos[i] - pos[i+1] ≤ 0`）
   - 反向后与 MD 边 `3 --(-3)--> 2` 构成负环：`pos[2] ≤ pos[3]` 且 `pos[3] ≤ pos[2] - 3` → `pos[2] ≤ pos[2] - 3` 矛盾
   - 导致样例输出 `-1`（误判为无解）

3. **SPFA 内部状态未重置**（已修复）
   - 第一次跑完负环检测后，dis / vis / cnt / 队列 存有旧数据
   - 第二次跑最短路前需要完整清零

---

**教训**：

1. 差分约束建边前，**先写出不等式**，手动推导一遍最短路形式，确定起点终点方向
   - 标准化：`x_j - x_i <= c` → 边 `i --c--> j`
   - 链式：`x_3 - x_1 <= 10, x_2 - x_3 <= -3, x_4 - x_2 <= 20` → 路径 `1->3->2->4` 和为 27
2. **顺序约束一定是 `pos[i] ≤ pos[i+1]` → `pos[i] - pos[i+1] ≤ 0` → 边 `(i+1) --0--> i`**
   - 方向口诀："小编号 → 大编号 = 正方向"不对，要看不等号方向
   - 推导：`pos[i] ≤ pos[i+1]` 移项为 `pos[i] - pos[i+1] ≤ 0`，左边是 i 减 i+1，所以边是 `(i+1) → i`
3. 跑完负环检测后要**彻底重置** dis / vis / cnt / 队列，才能进行第二次最短路
