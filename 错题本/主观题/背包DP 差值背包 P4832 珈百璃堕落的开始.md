题目链接：https://www.luogu.com.cn/problem/P4832
标签：背包DP / 差值背包（0/1 背包 + 差值维 + 全局偏移坐标）/ 恒等式转化

**思路**：
- 每个式子 = 若干 `sin²(pi/7)`(记作 `s`) 与 `cos²(pi/7)`(记作 `c`) 相加，`m` 为所有式子中 `s`、`c` 总数，`n*m <= 5e7`。
- 由恒等式 `sin²x + cos²x = 1`（与 `x` 无关，所以 `x=pi/7` 只是幌子）知：某方案的和为**整数**，当且仅当选中的式子中 `s` 总数 `S` = `c` 总数 `C`，且此时和恰为 `S(=C)`。
  - 严格说 `S*sin² + C*cos² = (S+C)/2 + (C-S)/2 * cos(2pi/7)`，而 `cos(2pi/7)` 是无理数，故 `S != C` 必非整数。
- 于是答案 = `max{ S | 选中某些式子满足 Σ(s-c) = 0 }`。这是**差值背包**：
  - 每个式子作为一个物品，重量 `w = s - c`（可为负），价值 `= s`；
  - `dp[j]` = 已选式子差值总和为 `j` 时 `s` 个数和的最大值；答案 `= dp[0]`。
  - 转移 `dp[t][j] = max(dp[p][j](不选), dp[p][j-w] + s(选))`，按 `i&1` 滚动两行。
- 差值可负，数组加全局偏移 `offset`。初始 `dp[0][offset] = 0`，答案 `ans = dp[t][offset]`。

**错点**：
- 误当"最大整数答案 = max floor(总和浮点值)"：样例/裸配例里看似够大，但 `sin²≈0.1883`、`cos²≈0.8117`，`floor` 结果与"恰为整数"答案不同（如 `cc`+`ccc` 时 `floor` 为 4，但无法凑成整数，正确应为 0）。
- 用浮点实算 `sin/cos`：没必要且爆精度，直接数每行 `s`、`c` 的个数即可。
- 死算 O(n*m)：最初枚举整个 `[0, 2m]` 区间做转移，`n*m <= 5e7` 直接超时；且转移取 `dp[p][j-g]` 时 `j-g` 可能越出数组 → RE。
- 差值维坐标换算：`j` 是**差值**而非索引，访问须写 `dp[t][j + MAXM]`；漏偏移或直接当索引会导致越界（上一版 TLE&RE 的根因）。

**关键结论**：
- "相加求最大整数" + 含 `sin²x、cos²x` → 恒等式 `sin²+cos²=1` 把问题转成"凑 `S=C`"，再转差值背包。
- 差值背包模板：重量可为负，用 `[l, r]` 记录当前可达差值区间，只扫该区间，随加入物品 `l=l+w`、`r=r+w` 扩展；总扫描量 `O(Σ 区间宽) <= O(n*m)`，由 `n*m <= 5e7` 卡稳。
- 坐标压缩：差值维只需 `[-m, m]`，开 `2m+?` 大小 + 偏移即可。复杂度 `O(n*m)` 时间、`O(m)` 空间（`m <= 1e6` 约 16 MB）。
- 对拍技巧：用 Python 暴力枚举所有子集，比较"S=C 时的 max S"与实现输出，随机 300 例一致。
