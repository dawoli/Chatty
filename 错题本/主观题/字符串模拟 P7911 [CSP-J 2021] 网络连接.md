# 字符串模拟 P7911 [CSP-J 2021] 网络连接

- **题目链接**：<https://www.luogu.com.cn/problem/P7911>
- **标签**：字符串模拟 / map
- **难度**：普及-（CSP-J T3）

## 题意

有 $n$ 台计算机，每台发一条 `Server ad` 或 `Client ad` 指令。`ad` 是形如 `a.b.c.d:e` 的地址串。

- 地址合法需满足：恰好 3 个 `.`、1 个 `:`；$a,b,c,d\in[0,255]$，$e\in[0,65535]$；每段非负整数且**无多余前导 0**。
- **Server**：地址不合法 → `ERR`；地址已被别的服务机占用 → `FAIL`；否则成功建连，登记地址 → `OK`。
- **Client**：地址不合法 → `ERR`；有服务机用过相同地址 → 输出那台**服务机编号**；否则 → `FAIL`。

数据范围：$n\le 1000$，`ad` 长度 $\le 25$。

## 算法思路

1. `is_valid` 先扫一遍字符串：统计 `.` 数量（必须 3）和 `:` 数量（必须 1），顺带把不是数字、`.`、`:` 的字符判为非法（`ERR`）。
2. 用 `find(':')` 把串切成 `ip` 与 `port`；`ip` 再按 `.` 切成 4 段。
3. 抽一个 `check_num(s, low, high)` 复用：非空 → 无前导 0（长度 $>1$ 且首字符为 `0` 即非法）→ 全数字 → 数值落在 `[low, high]`。ip 四段传 `[0,255]`，端口传 `[0,65535]`。
4. 用 `map<string,int> server` 登记服务机地址 → 编号实现去重。客户端只查 `.count(ad)`，不登记自己。

## 踩坑点

- **前导 0**：`192.168.00.1:10`、`192.168.0.1:088` 都是非法。判断是「长度 $>1$ 且首字符 `'0'`」，别只看是否等于 `"0"`。
- **空段 / 非法字符**：不能只数分隔符，`.1.2.3:4`（空首段）、`a.b.c.d:e` 里有字母都要判 `ERR`。
- **范围上限分开**：ip 段是 $255$，端口是 $65535$，写错上限会挂样例 2 的第 6/10 行（`192.168.1.999:0` → `ERR`）。
- **客户机不占位**：两台客户机用同一地址合法；客户机地址不该写进 `server` 表，否则会错误地让后续客户机「连上」一台本不存在的客户机。查无匹配输出 `FAIL`，不是 `ERR`。
- **防止溢出**：读数字时发现 `val > high` 立即 `return false`，避免长数字串让 `long long` 溢出。
- **样例 1 验证端口越界**：`Client 192.168.1.1:99999` → `ERR`（端口 > 65535）。

## 关键结论

- 字符串格式校验题，忙先把「结构合法」和「数值合法」拆开：结构用计数分隔符 + 切段，数值用统一 `check_num`。
- 无前导 0 是一个非常普适的细节，几乎所有「数字串格式」题都会考；把判断做成独立函数可复用也防漏。
- 本题省却了地址转数字再比较的麻烦——直接用 `string` 做 map 的 key，因为「格式相同 + 无前导 0」保证合法地址的字符串表示唯一。
- 复杂度 $O(n\log n + n\cdot\mathit{len})$，常数很小，$n\le1000$ 毫无压力。
